# NetPulse

Sistema web para la gestión y monitoreo de infraestructura tecnológica.

## Descripción

NetPulse permite administrar y monitorear los recursos tecnológicos,
incidencias, mantenimientos y demás procesos relacionados con la
infraestructura tecnológica.
